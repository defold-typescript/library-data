Insality/defold-quest/quest

Quest system library for Defold games. Manage quests, objectives, and quest progression. Track events and customize behavior.

  • GitHub: Insality/defold-quest — pinned to 3
    1. Pick a release from Insality/defold-quest releases and add its Source code (zip) URL (or a packaged .zip asset, if the library ships one) to game.project under [project] dependencies, then Fetch Libraries in the Defold editor.
    2. Run bunx @defold-typescript/cli resolve to materialize its types.
    3. Import it under a namespace alias of your choice:

get_current_with_task(action: string, object?: string | undefined): string[]

Get current quests that have tasks matching the specified action and object. Returns an array of quest IDs that contain matching tasks. local quests = quest.is_current_with_task("kill", "enemy") if #quests > 0 then print("Found " .. #quests .. " quests with kill enemy task") end

local quests = quest.is_current_with_task("collect") for i, quest_id in ipairs(quests) do print("Quest " .. quest_id .. " has collect task") end

Parameters

  • action: string — Action to check (e.g., "kill", "collect")
  • object?: string | undefined — Object to check (e.g., "enemy", "coin"). Can be nil for any object

Returns

  • string[] — List of quest IDs that have matching tasks

If true, the quest events will be stored and processed even quest is not active

If true, the quest will be not stored in the completed list
