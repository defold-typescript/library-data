thejustinwalsh/defold-xmath/xmath

Mathematical operations for vectors, quaternions, and matrices

  • GitHub: thejustinwalsh/defold-xmath — pinned to v1.0.1 (released while Defold 1.13.0 was current)
    1. Pick a release from thejustinwalsh/defold-xmath releases and add its Source code (zip) URL (or a packaged .zip asset, if the library ships one) to game.project under [project] dependencies, then Fetch Libraries in the Defold editor.
    2. Run bunx @defold-typescript/cli resolve to materialize its types.
    3. Import it under a namespace alias of your choice:
  • Asset Portal: defold-xmath

xmath.lerp(t_or_out: number | vector3 | vector4 | quaternion, n1_or_t: number | vector3 | vector4 | quaternion, n2_or_v1: number | vector3 | vector4 | quaternion, v2: vector3 | vector4 | quaternion): number

Linearly interpolate between two numbers, vectors, or quaternions. For numbers, pass (t, n1, n2) and returns the interpolated number. For vectors/quaternions, pass (v_in_place, t, v1, v2) to modify v_in_place.

Parameters

  • t_or_out: number | vector3 | vector4 | quaternion — For numbers, the interpolation factor. For vectors/quaternions, the output value to store the result.
  • n1_or_t: number | vector3 | vector4 | quaternion — For numbers, the start value. For vectors/quaternions, the interpolation factor.
  • n2_or_v1: number | vector3 | vector4 | quaternion — For numbers, the end value. For vectors/quaternions, the start value.
  • v2: vector3 | vector4 | quaternion — For vectors/quaternions only, the end value.

Returns

  • result: number — For number inputs, returns the interpolated number. For vector/quaternion inputs, modifies v_in_place and returns nothing.

xmath.clamp(value_or_out: number | vector3 | vector4, value_or_min: number | vector3 | vector4, min_or_max: number | vector3 | vector4, max: number | vector3 | vector4): number

Clamp input value in range [min, max]. For numbers, pass (value, min, max) and returns the clamped number. For vectors, pass (v_in_place, value, min, max) to modify v_in_place. min and max can be numbers or matching vector types.

Parameters

  • value_or_out: number | vector3 | vector4 — For numbers, the value to clamp. For vectors, the output vector to store the result.
  • value_or_min: number | vector3 | vector4 — For numbers, the minimum value. For vectors, the value to clamp.
  • min_or_max: number | vector3 | vector4 — For numbers, the maximum value. For vectors, the minimum value.
  • max: number | vector3 | vector4 — For vectors only, the maximum value.

Returns

  • result: number — For number inputs, returns the clamped number. For vector inputs, modifies v_in_place and returns nothing.
