widgrensit/asobi-defold/asobi.realtime

The realtime connection a client creates as client.realtime: one websocket that authenticates the session, carries matchmaking, matches, worlds, chat, votes and extension calls, and keeps a registry of the entities the server syncs.

  • GitHub: widgrensit/asobi-defold — pinned to v1.18.1
    1. Pick a release from widgrensit/asobi-defold releases and add its Source code (zip) URL (or a packaged .zip asset, if the library ships one) to game.project under [project] dependencies, then Fetch Libraries in the Defold editor.
    2. Run bunx @defold-typescript/cli resolve to materialize its types.
    3. Import it under a namespace alias of your choice:

Realtime.on<E extends keyof RealtimeEvents>(event: E, callback: RealtimeEvents[E])

Registers a handler for an event. A name RealtimeEvents does not list raises an error, and handlers for one event run in the order they were registered. The reply to a request made with a callback goes to that callback rather than to an event.

Parameters

  • event: E — The event.
  • callback: RealtimeEvents[E] — The handler.

Realtime.connect()

Opens the websocket and authenticates with the client's access token. Set request_binary_wire and request_datagram before calling it, and register handlers first. Does nothing while connected.

Realtime.update()

Drains the datagram plane, and is a no-op without one. Call it once per frame from update when request_datagram is set.

Realtime.disconnect()

Closes the datagram plane and the websocket.

Realtime.reauth()

Re-authenticates the open socket with the client's current access token, after a token refresh. Does nothing when not connected.

Realtime.client: Client

The client this connection belongs to.

Realtime.entities: LuaMap<string, Payload>

Every synced entity's whole state, keyed by entity id. Emptied when a world is joined or left.

Realtime.local_player_id: string | undefined

The signed-in player's entity id, set once connected fires.

Realtime.request_binary_wire: boolean

Set before connect to ask for the binary world.tick encoding.

Realtime.wire: 'json' | 'binary'

The encoding the server granted, read once connected fires.

Realtime.request_datagram: boolean

Set before connect to also open the datagram plane, which carries entity positions over UDP. It never opens on HTML5, and the websocket keeps carrying everything either way.

RealtimeEvents

RealtimeEvents.error: (payload: RealtimeError) => void

An error frame, or { error } with the websocket's message when the socket fails. A frame whose reason rejects the access token fires auth_expired as well.

RealtimeEvents.connected: (payload: Payload) => void

session.connected: the session is authenticated, and local_player_id and wire are set. Send game messages only after this fires.

RealtimeEvents.heartbeat: (payload: Payload) => void

session.heartbeat: the server's heartbeat.

RealtimeEvents.match_state: (payload: Payload) => void

match.state: a match state snapshot. A { tick, updates } frame has already updated entities and fired the entity events and tick.

RealtimeEvents.match_matched: (payload: Payload) => void

match.matched: the matchmaker placed the player in a match, carrying its match_id.

RealtimeEvents.match_joined: (payload: Payload) => void

match.joined: the player joined a match.

RealtimeEvents.match_left: (payload: Payload) => void

match.left: the player left the match.

RealtimeEvents.match_list: (payload: Payload) => void

match.list: a list of matches.

RealtimeEvents.match_finished: (payload: Payload) => void

match.finished: the match ended.

RealtimeEvents.matchmaker_expired: (payload: Payload) => void

match.matchmaker_expired: the matchmaker ticket expired.

RealtimeEvents.matchmaker_failed: (payload: Payload) => void

match.matchmaker_failed: the match could not start, carrying a reason.

RealtimeEvents.vote_start: (payload: Payload) => void

match.vote_start: a vote opened.

RealtimeEvents.vote_tally: (payload: Payload) => void

match.vote_tally: a vote's running tally.

RealtimeEvents.vote_result: (payload: Payload) => void

match.vote_result: a vote's result.

RealtimeEvents.vote_vetoed: (payload: Payload) => void

match.vote_vetoed: a vote was vetoed.

RealtimeEvents.matchmaker_queued: (payload: Payload) => void

matchmaker.queued: the matchmaker accepted the ticket, carrying ticket_id and players_needed.

RealtimeEvents.matchmaker_removed: (payload: Payload) => void

matchmaker.removed: the ticket left the matchmaker.

RealtimeEvents.chat_joined: (payload: Payload) => void

chat.joined: the player joined a chat channel.

RealtimeEvents.chat_left: (payload: Payload) => void

chat.left: the player left a chat channel.

RealtimeEvents.chat_message: (payload: Payload) => void

chat.message: a message in a joined channel.

RealtimeEvents.dm_sent: (payload: Payload) => void

dm.sent: a direct message was sent.

RealtimeEvents.dm_message: (payload: Payload) => void

dm.message: a direct message arrived.

RealtimeEvents.presence_changed: (payload: Payload) => void

presence.updated: a player's presence changed.

RealtimeEvents.notification: (payload: Payload) => void

notification.new: a new notification.

RealtimeEvents.game_message: (payload: Payload) => void

game.message or module.message: a message from the game module. The server sends both names for each message, and the event fires for whichever the connection saw first.

RealtimeEvents.game_error: (payload: Payload) => void

game.error or module.error: an error from the game module. The server sends both names for each error, and the event fires for whichever the connection saw first.

RealtimeEvents.module_event: (payload: Payload) => void

module.event: a named push from a server extension, carrying event and data.

RealtimeEvents.vote_cast_ok: (payload: Payload) => void

vote.cast_ok: the vote was recorded.

RealtimeEvents.vote_veto_ok: (payload: Payload) => void

vote.veto_ok: the veto was recorded.

RealtimeEvents.world_tick: (payload: Payload) => void

world.tick: a world frame. It has already updated entities and fired the entity events and tick.

RealtimeEvents.world_terrain: (payload: Payload) => void

world.terrain: the world's terrain.

RealtimeEvents.world_list: (payload: Payload) => void

world.list: a list of worlds.

RealtimeEvents.world_joined: (payload: Payload) => void

world.joined: the player joined a world. entities is emptied first.

RealtimeEvents.world_left: (payload: Payload) => void

world.left: the player left the world. entities is emptied first.

RealtimeEvents.phase_changed: (payload: Payload) => void

world.phase_changed: the world's phase changed.

RealtimeEvents.world_finished: (payload: Payload) => void

world.finished: the world ended.

RealtimeEvents.world_ack: (ack: WorldAck) => void

world.ack: the highest input seq the server consumed. It fires only for inputs sent with a seq.

RealtimeEvents.auth_expired: (reason: string) => void

The server rejected the access token: the socket closed, or an error frame arrived, for a revoked, invalid or idle-timed-out session. Sign in again rather than retrying.

RealtimeEvents.disconnected: (reason: string) => void

The socket closed for any other reason, "closed" when it gave none.

RealtimeEvents.entity_added: (id: string, state: Payload) => void

An entity entered entities, with its full initial state.

RealtimeEvents.entity_updated: (id: string, state: Payload, changed: string[]) => void

An entity changed. state is its whole merged state, never a partial one, and changed names the fields that changed.

RealtimeEvents.entity_removed: (id: string) => void

An entity left entities.

RealtimeEvents.tick: (tick: number | undefined, payload: Payload) => void

A world.tick or match.state frame was applied, after its entity events.

RealtimeEvents.match_event: (name: string, payload: Payload) => void

A match.<name> frame that a match script sent with game.broadcast(name, payload). Frames asobi itself sends keep their own events.

RealtimeEvents.world_event: (name: string, payload: Payload) => void

A world.<name> frame that a world script sent with game.broadcast(name, payload). Frames asobi itself sends keep their own events.

The world tick the input was consumed by.

WorldAck.seq: number

The highest seq passed to send_world_input that the server has consumed.

Only sessions of this mode.

MatchmakerOptions.mode?: string

The matchmaker mode. Defaults to "default".

MatchmakerOptions.properties?: Payload

Properties the matchmaker groups tickets by.

The error code, "internal" when the server sent none.

A message for people, which may be reworded at any time.

Further detail the method attached.
