defold/extension-rive/rive.cmd

Command queue helpers for interacting with the Rive runtime

  • GitHub: defold/extension-rive — pinned to 13.1.0 (released while Defold 1.13.1 was current)
    1. Pick a release from defold/extension-rive releases and add its Source code (zip) URL (or a packaged .zip asset, if the library ships one) to game.project under [project] dependencies, then Fetch Libraries in the Defold editor.
    2. Run bunx @defold-typescript/cli resolve to materialize its types.
    3. Import it under a namespace alias of your choice:
