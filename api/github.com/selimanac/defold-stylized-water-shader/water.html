selimanac/defold-stylized-water-shader/water

A stylized water shader: animated wave surfaces, foam, sparkles, refraction and reflection, set through shader constants. A game object script calls init once with the camera, sun and water objects, then update(dt) and update_camera() every frame. The render script calls render_init(self) at the end of its init, after which self.predicates holds the water predicate, and render_update(self, state, self.predicates, draw_options_world) in its update (see water/render/water.render_script). The shader needs exclude_gles_sm100 = 1 under [shader] in game.project. Every setter writes a shader constant the next render_update uploads, and every getter returns the stored values as separate values.

  • GitHub: selimanac/defold-stylized-water-shader — pinned to bdcc1d8
    1. This repo publishes no releases or tags. Add a commit archive URL — for the pinned commit, https://github.com/selimanac/defold-stylized-water-shader/archive/bdcc1d863c64015fb70b117042f551795eb04211.zip — to game.project under [project] dependencies, then Fetch Libraries in the Defold editor.
    2. Run bunx @defold-typescript/cli resolve to materialize its types.
    3. Import it under a namespace alias of your choice:

init(camera_url: Url | string | Hash, camera_component_url: Url | string | Hash, sun_url: Url | string | Hash, water_url: Url | string | Hash, time_speed: number)

Stores the camera, sun and water objects and the time speed, then reads the camera position and near and far planes and the sun direction once. Call it from a game object script's init.

Parameters

  • camera_url: Url | string | Hash — The camera game object, whose world position the shader uses.
  • camera_component_url: Url | string | Hash — The camera component, whose near and far Z planes the shader uses.
  • sun_url: Url | string | Hash — The sun game object, whose position sets the light and the sun direction.
  • water_url: Url | string | Hash — The water surface game object, the origin of the sun direction.
  • time_speed: number — The multiplier update applies to dt to advance the wave time.

render_init(self: RenderScriptSelf)

Adds the water predicate to self.predicates, creates the scene render target at self.state.width by self.state.height with a color and a depth buffer, and creates the two constant buffers render_update draws with, all stored on self. Call it at the end of the render script's init, once self.predicates and self.state are set. Afterwards self.predicates types as Predicates, which render_update takes. From a defineRenderScript init, call it on the state init returns, which is merged onto self.

Parameters

  • self: RenderScriptSelf — The render script instance.

render_update(self: object, state: RenderState, predicates: Predicates, draw_options_world: render.DrawOptions)

Draws the model predicate into the scene render target, then draws model and the water to the default render target, sampling the scene's depth and color for edge foam and refraction. It needs render_init to have run on the same self, and raises otherwise. Call it from the render script's update after the world view and projection are set.

Parameters

  • self: object — The render script instance render_init ran on.
  • state: RenderState — The render state: the window size and the clear values.
  • predicates: Predicates — The render script's predicates; pass self.predicates, which holds the water predicate render_init added.
  • draw_options_world: render.DrawOptions — The draw options for the world, used for the scene pass.

update_sun()

Re-reads the sun position, which moves the light and recomputes the sun direction from the water object, replacing any direction set_sun_direction wrote.

update_camera()

Re-reads the camera world position and its near and far Z planes. Call it every frame.

update(dt: number)

Advances the wave time by dt times the time speed init stored, unless the timer is paused. Call it every frame.

Parameters

  • dt: number — The frame time in seconds.

pause(state: boolean)

Pauses or resumes the wave timer.

Parameters

  • state: boolean — true stops the timer, false resumes it.

set_wave1(direction: number, amplitude: number, wavelength: number, speed: number)

Sets the first wave layer.

Parameters

  • direction: number — The wave direction in radians, 0 to 2π: 0 east, π/2 north, π west, 3π/2 south.
  • amplitude: number — The wave height: 0.1 to 0.5 gentle, 0.5 to 1 medium, 1 to 2 rough, above 2 a storm.
  • wavelength: number — The distance between wave peaks: 10 to 20 choppy, 20 to 40 ocean waves, above 40 long gentle swells.
  • speed: number — The animation speed: 0.5 to 1 slow, 1 to 3 moderate, 3 to 5 fast, above 5 very fast.
