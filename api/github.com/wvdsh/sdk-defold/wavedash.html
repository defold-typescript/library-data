Wavedash Defold API

  • GitHub: wvdsh/sdk-defold — pinned to 1.3.1 (released while Defold 1.14.0 was current)
    1. Pick a release from wvdsh/sdk-defold releases and add its Source code (zip) URL (or a packaged .zip asset, if the library ships one) to game.project under [project] dependencies, then Fetch Libraries in the Defold editor.
    2. Run bunx @defold-typescript/cli resolve to materialize its types.
    3. Import it under a namespace alias of your choice:
  • Asset Portal: sdk-defold

wavedash.fulfill_purchase_async(purchase_id: string): function

Mark a consumable purchase fulfilled once the grant is saved, so it stops being redelivered.   • response: function — Returns { status } in data. (Note: Only if called from within a coroutine)

wavedash.EVENT_PURCHASE_COMPLETED

Fired once per purchase made while the game is running (in-game paywall, game page, gift, another tab), plus, at launch, once per consumable still unfulfilled. Payload: { purchaseId, contentIdentifier, type, fulfilled, purchasedAt, receiptJwt }. Durables arrive with fulfilled true, already granted. For a consumable, grant it, then call fulfill_purchase_async(purchaseId); until then it's redelivered every launch, so dedupe on purchaseId if you persist grants.

wavedash.PURCHASE_TYPE_DURABLE

type field on the EVENT_PURCHASE_COMPLETED payload for content purchased once that never expires.

wavedash.PURCHASE_TYPE_CONSUMABLE

type field on the EVENT_PURCHASE_COMPLETED payload for content that can be purchased repeatedly and is fulfilled by the game.

wavedash.FULFILL_PURCHASE_STATUS_FULFILLED

fulfill_purchase_async status: marked fulfilled by this call.

wavedash.FULFILL_PURCHASE_STATUS_ALREADY_FULFILLED

fulfill_purchase_async status: also success. The game or its backend fulfilled it earlier, or it's a durable.

wavedash.FULFILL_PURCHASE_STATUS_NOT_FOUND

fulfill_purchase_async status: unknown purchase, or it was refunded. Don't grant it.
