Insality/defold-token/token

The Defold Token module. Used to manage all countable items in the game.

  • GitHub: Insality/defold-token — pinned to 9
    1. This repo publishes no stable release. Pick a tag from Insality/defold-token tags and add its Source code (zip) URL — for the pinned tag, https://github.com/Insality/defold-token/archive/refs/tags/9.zip — to game.project under [project] dependencies, then Fetch Libraries in the Defold editor.
    2. Run bunx @defold-typescript/cli resolve to materialize its types.
    3. Import it under a namespace alias of your choice:
