indiesoftby/defold-yagames/yagames

YaGames is the Yandex.Games SDK implementation for the Defold game engine.

  • GitHub: indiesoftby/defold-yagames — pinned to 0.19.0
    1. Pick a release from indiesoftby/defold-yagames releases and add its Source code (zip) URL (or a packaged .zip asset, if the library ships one) to game.project under [project] dependencies, then Fetch Libraries in the Defold editor.
    2. Run bunx @defold-typescript/cli resolve to materialize its types.
    3. Import it under a namespace alias of your choice:
