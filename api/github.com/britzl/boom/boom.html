britzl/boom

Boom is a game framework built on top of Defold.

  • GitHub: britzl/boom — pinned to 5d47820
    1. Pick a release from britzl/boom releases and add its Source code (zip) URL (or a packaged .zip asset, if the library ships one) to game.project under [project] dependencies, then Fetch Libraries in the Defold editor.
    2. Run bunx @defold-typescript/cli resolve to materialize its types.
    3. Import it under a namespace alias of your choice: Symbols marked ambient globals are declared globally and need no import — call them directly.
