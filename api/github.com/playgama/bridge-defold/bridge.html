Playgama/bridge-defold/bridge

Functions and constants for interacting with bridge

  • GitHub: Playgama/bridge-defold — pinned to v2.4.0
    1. Pick a release from Playgama/bridge-defold releases and add its Source code (zip) URL (or a packaged .zip asset, if the library ships one) to game.project under [project] dependencies, then Fetch Libraries in the Defold editor.
    2. Run bunx @defold-typescript/cli resolve to materialize its types.
    3. Import it under a namespace alias of your choice:

bridge.multiplayer.set_sync_state(state: table)

Set the local game world. When the room is entered with syncState, the host sends its world to the other players up to updatesPerSecond times a second (1-10, default 10) and they get it in the multiplayer_sync_state_received event. The server keeps the last world - a new host gets it in the same event and goes on from it. Works outside a room too, e.g. to set the starting world before create_room.
