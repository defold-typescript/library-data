  • GitHub: defold/extension-xsolla — pinned to 1.2.0 (released while Defold 1.10.2 was current)
    1. Pick a release from defold/extension-xsolla releases and add its Source code (zip) URL (or a packaged .zip asset, if the library ships one) to game.project under [project] dependencies, then Fetch Libraries in the Defold editor.
    2. Run bunx @defold-typescript/cli resolve to materialize its types.
    3. Import it under a namespace alias of your choice:
