baochungit/defold-wrap/wrap.node

A chainable wrapper around a GUI node. new wraps a node or looks one up by id, and each method calls the gui.* function of the same name with the wrapped node first: setters return the wrapper, so calls chain, and getters return what the engine does.

  • GitHub: baochungit/defold-wrap — pinned to 1.1.0
    1. Pick a release from baochungit/defold-wrap releases and add its Source code (zip) URL (or a packaged .zip asset, if the library ships one) to game.project under [project] dependencies, then Fetch Libraries in the Defold editor.
    2. Run bunx @defold-typescript/cli resolve to materialize its types.
    3. Import it under a namespace alias of your choice:
