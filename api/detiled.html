Insality/detiled

Tiled to Defold Map Parser.

  • GitHub: Insality/detiled — pinned to 3
    1. Pick a release from Insality/detiled releases and add its Source code (zip) URL (or a packaged .zip asset, if the library ships one) to game.project under [project] dependencies, then Fetch Libraries in the Defold editor.
    2. Run bunx @defold-typescript/cli resolve to materialize its types.
    3. Import it under a namespace alias of your choice:
