colyseus/colyseus-defold/colyseus

Open-source Multiplayer Framework. Run your game servers on Node.js and connect to them via the Defold SDK.

  • GitHub: colyseus/colyseus-defold — pinned to 0.18.2
    1. Pick a release from colyseus/colyseus-defold releases and add its Source code (zip) URL (or a packaged .zip asset, if the library ships one) to game.project under [project] dependencies, then Fetch Libraries in the Defold editor.
    2. Run bunx @defold-typescript/cli resolve to materialize its types.
    3. Import it under a namespace alias of your choice:

ClientConstructor.select_by_latency(this: void, endpoints: Array<string | ClientSettings>, callback: (err?: string, client?: Client) => void, timeout?: number)

Measures the latency of each endpoint and calls back with a client for the fastest.

Parameters

  • this: void
  • endpoints: Array<string | ClientSettings> — The endpoints to compare, each a URL or its settings.
  • callback: (err?: string, client?: Client) => void — Receives the fastest endpoint's client, or an error when the list is empty or no endpoint responded.
  • timeout?: number — Seconds to wait for each endpoint (default: 1.5).

A path prefix the server is mounted under, without a trailing /.
