Libraries

Library API blocks, and libraries that have no typed API.
The TypeScript definitions behind each API block are maintained in the library data repo — generated from the upstream sources that ship machine-readable types, and hand-forked where upstream ships none — and pinned to an upstream commit or tag.
A card marked with the no-typed-API icon links to a page describing what the library ships and how to use it, but it has no typed API.
269 namespaces documented.
